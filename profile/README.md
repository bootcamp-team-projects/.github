# Bootcamp Team Projects

AI·데이터 기반 서비스 개발 교육 과정에서 진행한 팀 프로젝트를 모아 둔 공간입니다.

## About

이 조직은 교육 과정에서 수행한 웹·앱 개발, 데이터 분석, 머신러닝·딥러닝 프로젝트를 정리하고 공유하기 위해 운영합니다. 각 저장소에는 프로젝트 코드와 README를 통해 목적, 주요 기능, 사용 기술 및 실행 방법을 기록합니다.

## Project Areas

- **Web & App Development** — 웹 서비스와 모바일 애플리케이션 구현
- **Data & Machine Learning** — 데이터 전처리, 분석 및 머신러닝 실습
- **Deep Learning** — 딥러닝 모델 및 관련 실습 프로젝트
- **Team Collaboration** — 팀 단위 기획, 개발, 협업 경험 기록

## Explore Projects

[전체 저장소 보기](https://github.com/orgs/bootcamp-team-projects/repositories)

프로젝트별 세부 내용과 기술 스택은 각 저장소의 README를 확인해 주세요. 저장소에 포함된 코드와 문서는 교육 및 포트폴리오 목적의 기록입니다.
